FILES IN THIS FOLDER:
------------------------------------------------------------------------
1. report.tex          - The complete LaTeX source document containing
                         all 8 chapters, literature review, requirements,
                         architecture, use case, DFD, relational schema,
                         Gantt chart, testing tables, and references.

2. compile_to_pdf.bat  - One-click batch script to automatically compile 
                         report.tex into report.pdf using pdflatex.

3. Screenshots/        - Subfolder for UI screenshots from the presentation.

HOW TO GENERATE report.pdf:
------------------------------------------------------------------------
Method A (Local with MiKTeX or TeX Live):
   - Double click `compile_to_pdf.bat` inside this folder.
   - It will run `pdflatex` twice to generate the Table of Contents,
     List of Figures, List of Tables, and output `report.pdf`.

Method B (Using VS Code):
   - Open `report.tex` in VS Code.
   - Install the extension "LaTeX Workshop".
   - Press Ctrl+Alt+B (or click Build LaTeX project) to compile to PDF.

Method C (Overleaf - Online):
   - Go to https://www.overleaf.com
   - Create a "New Project" -> "Blank Project".
   - Copy-paste the content of `report.tex` into `main.tex`.
   - Upload the images / screenshots.
   - Click "Recompile" and download `report.pdf`.
